# Event Calendar App

A responsive calendar application built with Next.js. Navigate between months, view the current date, and manage notes for specific days.

## Live Demo

- Frontend: https://frontend-event-calendar.vercel.app/
- Demo Video: https://www.loom.com/share/b2cb92627c2545d4966a9f155f4d833e

## Tech Stack

**Frontend:** Next.js, React.js, Tailwind CSS

**State Management:** React Hooks

**Deployment:** Vercel

## Features

- Current date highlight
- Month navigation — forward and backward
- Add and view notes per selected date
- Responsive UI across desktop and mobile
- Fast page loads with Next.js optimization

## Implementation Details

- Dynamic calendar grid generation based on month and year
- Conditional rendering for current date highlighting
- State-driven UI updates for selected dates and notes
- Modular component structure

## Local Setup

```bash
git clone https://github.com/karthiknani229-art/frontend-event-calendar.git
cd frontend-event-calendar
npm install
npm run dev
```

App runs at: http://localhost:3000
